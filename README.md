# Платежный календарь BAZA — 19–23 октября 2026

Статичная страница для GitHub Pages: расходы недели по направлениям, юрлицам, статьям и проектам с разбивкой на собственные и кредитные средства, поступления и таблица всех платежей.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | страница (оформление, графики, фильтры, таблицы) |
| `data.js` | данные недели: строки листа «Реестр» с крайней датой оплаты 19–23.10.2026, **без названий контрагентов** |
| `favicon.svg` | значок вкладки |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages |

Внешние ресурсы: шрифты Google Fonts (Inter, Unbounded) и библиотека d3 7.9.0 с cdnjs.

## Как опубликовать

1. На github.com создайте репозиторий, например `platezhny-kalendar`.
2. **Add file → Upload files**, перетащите все файлы из архива (вместе с `.nojekyll`), нажмите **Commit changes**.
   Скрытый файл `.nojekyll` проще загрузить, перетащив всю распакованную папку целиком.
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты страница откроется по адресу `https://<ваш-логин>.github.io/platezhny-kalendar/`.

## Важно про доступ

На бесплатном тарифе GitHub страница Pages и репозиторий **публичны**: их может открыть любой, кто знает адрес, без входа. В `data.js` остаются суммы, юрлица группы, статьи и проекты. Если это нежелательно, публикуйте из приватного репозитория на тарифе GitHub Enterprise (там Pages можно закрыть доступом организации) или используйте ссылку на страницу в Claude.

## Чем отличается от версии в Claude

- Названия контрагентов не показываются никому — в файлах их нет. Вместо них указан тип: «Внешний» или «Внутри группы».
- Статус согласования берётся из реестра и не меняется со страницы; колонки комментариев нет. Для общих отметок и комментариев нужен сервер, которого у GitHub Pages нет.

## Как обновить на следующую неделю

Замените `data.js` новым файлом того же формата (`window.PAYMENTS = [ ... ]`, поля: `n, date, flow, entity, funding, direction, project, article, subarticle, counterparty_type, approved, amount`) и поправьте даты в заголовке `index.html`. Проще всего — попросить Claude собрать новый архив по свежему реестру.
